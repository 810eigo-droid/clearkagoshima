## B. 文章として直した方がよい箇所

1. **ファーストビューが二重になっている**
   「肩こりも、腰のつらさも。〜そんな方のための整体サロンです。」の直後に、ほぼ同じ内容の「理学療法士が身体の状態や動きを確認し、〜女性のための整体サロンです。」が続いている。WordPress上で下書きが2案残ったままと思われる。どちらか1つにする（修正案では後者を残し、前者の「まずは今の身体の状態を知るところから」だけ活かした）。
2. **「身体との付き合い方」がFVだけで3回**出てくる。キャッチコピー1回に絞る。
3. **ステップ③の文**「運動やセルフケアを、実際に身体を動かし、動きや筋肉の使い方を確認します」は主語と述語がかみ合っていない。→「実際に身体を動かしながら、動きや筋肉の使い方まで確認します」。
4. **「効果が出なかったり、間違えた動きで身体を痛めないためにも」**は「〜たり」が片方だけ。→「効果が出なかったり、間違えた動きで身体を痛めたりしないためにも」。
5. **「肩こり、腰痛など様々なストレッチ動画やグッズ、情報であふれています。」**は主語がない。→「世の中には、肩こり・腰痛向けのストレッチ動画やグッズ、情報があふれています。」
6. **お客様の声の3件目**だけ「年代／お悩み」が無い。追記する。
7. **「私自身が無理な勧誘など嫌いなので」**はやや口語的。→「私自身、無理な勧誘が好きではありませんので」。

## C. 業者に伝えないと作れない箇所（プレースホルダー）

- 「整体初めての方のお声▼」「自分は身体が硬いと思い込んでいた方のお声▼」「お客様のお声▼」の3つは、**何を表示するのか未指定**。
  - 案: 「clearをご利用いただいた方の声」セクションへのページ内リンク、または該当口コミのスクリーンショット画像。
  - どちらにするか、画像なら素材をこちらから渡す必要がある。
- 先頭の「コンテンツへスキップ」と末尾の「PAGE TOP」はCocoonテーマのUIで、原稿ではない（業者には無視してもらう）。
- CTAボタンの文言は「【空席を確認して予約する】」「初回半額で体験する」「【ホットペッパーで予約する】」「初回60分　アドバイスシート付で予約する」「身体の状態を確認する」と5種類。
  - 【】はボタン上では不要なので外す。
  - 種類は2〜3に絞った方が計測しやすい（例: 「初回半額で予約する」「まずはLINEで相談する」）。
  - 納品後に自分で変えられる前提なので、初期値だけ決めればよい。

## D. 構成の見直し（料金を下げられる可能性が高い）

業者は「12〜13セクション」「6セクション分の追加料金」と言っているが、原稿には**内容が重複しているセクション**があり、統合すればセクション数を減らせる。

| 重複しているもの | 提案 |
|---|---|
| 「clearは施術を受けて終わりにしません」①〜④ と 「初回60分の流れ」01〜05 | ほぼ同じ内容。**「初回60分の流れ」1つに統合**し、③の「動画だけだと自己流になる」説明を04に移す |
| 「何をしたらいいかわからないから卒業」 と 「clearが大切にしている3つのこと」 | 前者は後者の01と同じ主張。**「3つのこと」の導入文に吸収** |
| 「40代・50代の身体と、これからも付き合っていくために」 と 「最後に」 | どちらも「年齢のせいにせず、まず身体を知る」で締めている。**「最後に」に統合** |
| 「女性が安心して相談できる場所へ」 と アクセス／通いやすい環境 | 「完全個室」「産婦人科2F」が両方に出る。**環境の箇条書きはアクセスに寄せる** |

これで 16セクション → 12前後になり、「追加6セクション」の根拠が減る。
業者自身も「15,000円でできる組み立て方にならないか」と言っているので、統合案を出して再見積もりを頼む価値がある。
