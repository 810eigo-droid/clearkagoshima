# Fonts

Noto Sans JP, Google Fonts / SIL Open Font License 1.1. Downloaded 2026-09-20 from fonts.gstatic.com. Public standard font downloads only; no manuscript text was sent to the font service.

Subsetted locally to the approved LP characters and ASCII. Embedded in clear-fonts.css to keep WordPress copy/paste portable, with no runtime font-service calls. New characters fall back to system fonts. Original license is in OFL.txt.
