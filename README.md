## 表示方法

`index.html` をブラウザで開けば表示できます。外部ライブラリ、フォントの通信、インストールは不要です。

Node.jsがある場合は、このフォルダで `npm start` を実行し、`http://127.0.0.1:4173` を開いてください。

## 編集方法

- `content/approved-copy.json`：ユーザーから受け取った確定原稿。本文の編集はクライアント確認後に行ってください。
- `content/approved-copy.md`：確認用原稿。
- `build.cjs`：ページ構成・表示テンプレート。
- `styles.css`：配色・文字サイズ・レイアウト。
- `design-v2.css`：参考画像を踏まえた曲線・重なり・タイポグラフィのデザイン。
- `design-details.cjs`：確定原稿を保ったまま強調とコラージュを組み立てる処理。
- `fonts/`：Noto Sans JPの軽量化フォントとライセンス。日本語の書体を端末間で揃えます。
- `images/`：既存リポジトリの写真。画像ファイルは変更していません。
- `index.html`：生成済みページ。`npm run build` で再生成できます。

変更後は `npm run build` を実行し、ブラウザを再読み込みしてください。ビルド時に通信は発生しません。

## デザイン方針

40代・50代以上の女性向けに、清潔感と落ち着き、専門性、ほどよい華やかさを両立。生成り、くすんだ緑、墨黒、落ち着いたオレンジを使用。スマートフォンの主要本文18px、ヒーロー補助コピー20px、注意書き・補足原則16px以上。日本語フォントNoto Sans JPをローカルで軽量化し同梱。ページ閲覧時にGoogle Fonts等への通信は行いません。

参考画像を踏まえ、太いゴシック体の強弱、オレンジの手描き風下線、曲線で切り抜いた写真と小写真の重なり、傾けたフレーム、丸い実績表示、大小の数字、ドット模様を追加しました。数字・資格・本文は確定稿に基づいています。強調や装飾のために文字を小さくすることは避け、本文・ボタンの読みやすさを維持しています。

全セクションに最低1画像。写真は既存の5種類を使用し、部分によって再利用しています。口コミに人物写真を紐づけていません。追加の実写素材が届けば写真のバリエーションを増やせます。

## 口コミ画像の追加

口コミのスクリーンショットは後日受領予定です。確定稿にある3件の口コミはすべてテキストで表示済みです。FAQ内の「整体初めての方のお声▼」「自分は身体が硬いと思い込んでいた方のお声▼」「お客様のお声▼」は、対応する画像を受領後に掲載してください。画像のない予告ラベルは現時点の公開表示から外し、元原稿には保存しています。

`build.cjs` のFAQ・口コミ部分に挿入位置のコメントがあります。画像の文字だけにせず、読める大きさのテキストも残してください。
