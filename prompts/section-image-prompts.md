# セクション別・画像制作プロンプト

各セクションで画像を使い回さず、専用画像を用意します。ファーストビューのPC・スマホ版のみ同じ素材を別構図で使用します。
各「共通指示」と「個別指示」をセットで画像生成に渡してください。
先生・施術・店舗は実写真を添付してください。口コミは実際のスクリーンショットを使用します。

## 保存先

ブランチ：`codex/clear-lp-design`
画像フォルダ：`images/sections/`
完成した順に下記のファイル名で追加してください。画像追加後、LPへの組み込み・軽量化・トリミングを行います。追加だけでは現在の画像は自動で置き換わりません。

## 共通指示（毎回添付）

```text
40代・50代の女性向け整体サロン「clear」のLP用画像を制作してください。
清潔感、専門家への信頼、温かさ、控えめな高級感を表現してください。
色はアイボリー、落ち着いたセージグリーン、深緑を中心に、スミクロで引き締め、柔らかいオレンジを少量アクセントにしてください。
茶色を主役にせず、原色、金色、過度な光沢は避けてください。
自然光のような柔らかい明るさ、自然な肌の質感、雑誌の特集写真のように余白のある上品な構図にしてください。
人物は不自然な笑顔や若返り加工を避けてください。
曲線での切り抜きや装飾はWeb側でも加えるため、画像自体には枠、波線、丸いバッジなどを焼き込まず、顔・手・身体の周囲にトリミング用の余白を残してください。
文字、数字、ロゴ、透かし、予約ボタンは入れないでください。
先生が登場する場合は添付した本人の写真を使用し、顔立ち・年齢・体格を変えないでください。
店舗が登場する場合は添付した実際の店舗写真を使用し、設備や内装を新しく作り足さないでください。
```

1600×1200／03-personal-care.jpg


### 05-flow-02-treatment.jpg

```text

身体を強くひねる演出や、実写真にない手技は加えないでください。
先生の手と利用者の身体の関係が分かる距離で切り取ってください。
```

### 05-flow-03-selfcare.jpg

```text
添付した実際の運動指導写真をもとに、女性が自分で動作し、先生がそばで確認している場面に整えてください。
「自宅でも続けられる方法を一緒に確認する」という雰囲気。
動作は元写真に忠実にし、必要な手足を画面内に収めてください。
激しいトレーニングや難しいヨガのポーズにはしないでください。
```
