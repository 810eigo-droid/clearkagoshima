# ファーストビュー生成の手順

1. ChatGPTに `images/check-posture.webp` と `images/profile-onishi.webp` を添付する。
2. `hero-pc.txt` の全文を送り、PC用画像を1枚生成する。
3. PC版の文字・顔・手・配色を確認する。
4. 同じ会話にPC完成画像と元写真を添付し、`hero-mobile.txt` の全文を送る。
5. スマホ用の文字が小さくなっていないか、実際にスマホ幅で確認する。

PCは1920×1080、スマホは1080×1920を希望サイズにしています。ツールの対応解像度により近いサイズで出力される場合は、縦横比と可読性を優先します。

画像内に掲載するのは確定稿の冒頭コピー・ブランド名・所在地情報のみです。原稿の続きはWeb上の通常テキストとして残します。予約ボタンは画像に含めず、実際にクリックできるHTMLボタンを画像の直下に置きます。

画像が完成するまでは既存のHTMLファーストビューを維持します。画像の差し替え方法は `wordpress/README.md` を参照してください。
